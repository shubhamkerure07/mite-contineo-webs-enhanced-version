## 📌 Overview

An enhanced, student-centric reimagination of the MITE Contineo collegiate portal. Engineered with a responsive modern UI and integrated AI assistant to simplify accessing academic schedules, attendance tracking, and campus updates.

---

## ✨ Features

- 🤖 **Academic AI Assistant**: Answers common questions regarding college schedules, courses, and portal navigation.
- 📱 **Mobile-First Design**: Optimized layout for smartphones and laptops.
- ⚡ **Lightning Fast**: Built on Vite and modern React components.
- 🎨 **Modern Ergonomics**: High-contrast, clean typography for better readability.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **AI Integration**: Google Gemini API
- **Deployment**: Modern web standards

---

## 🚀 Setup & Run

```bash
git clone https://github.com/shubhamkerure07/mite-contineo-webs-enhanced-version.git
cd mite-contineo-webs-enhanced-version
npm install
npm run dev
```
