## 🚀 Getting Started

**Prerequisites:** Node.js

```bash
git clone https://github.com/shubhamkerure07/mite-contineo-webs-enhanced-version.git
cd mite-contineo-webs-enhanced-version
npm install
```

Copy `.env.example` to `.env.local` and set your `GEMINI_API_KEY`.

```bash
npm run dev
```
